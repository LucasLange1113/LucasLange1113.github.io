# Lucas Lange — Portfolio

A responsive, accessible personal portfolio built as a dependency-free static site for GitHub Pages. W3 is now the single final design and loads directly from `index.html`.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a repository named `<your-github-username>.github.io`.
2. Push the files in this folder to its `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. The site will be available at `https://<your-github-username>.github.io`.

The site uses no build step and no third-party runtime dependencies.
